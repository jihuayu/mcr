# win-002: Remove Mistaken Non-Windows Backends From mcr-win

## Objective

Delete the mistakenly added non-Windows backends and stubs from `mcr-win` so
the host adapter crate is Windows x86-64 only, matching the supported host
platform.

## Context

- `docs/architecture/README.md`
- `docs/architecture/runtime.md`

## Path

- `crates/mcr-win/`

## Verification

```powershell
cargo ci-fmt
cargo ci-clippy
cargo test -p mcr-win
cargo ci-test
```

## Notes

- The Linux `libc` target dependency in `crates/mcr-win/Cargo.toml` and every
  `cfg(not(windows))` / `cfg(target_os = "linux")` backend or stub module
  (including `network/platform/stubs.rs` and the Linux branch of
  `native_exec.rs`) were written by mistake; Windows is the only supported
  host.
- After removal the workspace builds and tests on Windows only. CI (`ci.yml`)
  and the x86 smoke workflow already run exclusively on `windows-latest`, so
  no workflow change is expected beyond confirming green runs.
- Keep the `HostError`/`HostErrorKind` shape platform-neutral in naming; this
  task removes dead platform branches, it does not redesign the error model.
- Supersedes the win-001 note that allowed non-Windows compile-time stubs for
  unit tests.
