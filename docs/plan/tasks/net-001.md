## Notes

- Cover `socket`, `connect`, `bind`, `listen`, `accept`, `sendmsg`, `recvmsg`, `getsockopt`, `setsockopt`, and `shutdown` as needed by smoke tests.
- Raw sockets and network namespaces are unsupported.
- Guest-visible DNS prerequisites now exist through rootfs materialization of `/etc/hosts`,
  `/etc/resolv.conf`, and `/etc/nsswitch.conf` plus UDP datagram socket syscall coverage in
  `mcr-net`/`mcr-runtime`; `net-001` does not require a separate runtime host resolver API.
- The remaining gate is native x86 guest proof that libc-based resolution works end to end for the
  `example.com`/`git clone` paths under the Phase 2 smoke contract.
- Do not treat Alpine host-shell smoke as proof for this task. Final integration proof now runs through native x86 guest execution, typically via the `x86-runtime-smoke.yml` GitHub Actions workflow or an equivalent x86_64/QEMU environment.
