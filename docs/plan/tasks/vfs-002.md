# vfs-002: Implement P0 File And Directory Syscalls

## Objective

Connect P0 file syscalls to real VFS behavior: `openat`, `read`, `write`, `readv`, `writev`, `close`, `lseek`, `fstat`, `newfstatat`, `statx`, `access`, `readlink`, and `getdents64`.

## Context

- `docs/architecture/runtime.md`

- `crates/mcr-sys/`
- `crates/mcr-runtime/`


## Notes

- Cover Linux errno behavior for missing paths, invalid fds, non-directory traversal, and permission-denied cases.
- Directory entry layout must match Linux `getdents64` expectations.
