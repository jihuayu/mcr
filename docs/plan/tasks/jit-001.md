# jit-001: Add Syscall Trampoline Execution Core

## Objective

Implement the same-ISA execution core that decodes guest x86-64 blocks, identifies `syscall`, preserves register state, and calls the syscall dispatcher through a trampoline interface.

## Context

- `docs/architecture/runtime.md`

## Path

- `crates/mcr-jit/`
- `crates/mcr-sys/`
- `crates/mcr-runtime/`

## Verification

```powershell
cargo test -p mcr-jit
```

## Notes

- Use `iced-x86` unless a design doc update justifies another decoder.
- Local tests can use synthetic guest code that writes registers and triggers a dispatcher callback.
